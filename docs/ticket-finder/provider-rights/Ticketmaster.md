# Ticketmaster Discovery API rights record

Operator approval supplied for the Ticketmaster Public Discovery API and the
Consumer Key. This repository treats Ticketmaster as an official-event,
`event-summary` source only. The approved integration uses attraction
`K8vZ9171oU7`; it does not imply Inventory Status, listing-level inventory,
affiliate, logo, seat-map, or trademark rights.

Displayable Discovery fields are event identity/name/URL, attractions, venue,
date/time/timezone, event and public-sale status, classifications, and genuine
`priceRanges`/`allInclusivePricing` fields when returned. Event price ranges
are never represented as individual listings or ranked as cheapest. Raw API
responses and credentials are not published or retained.
